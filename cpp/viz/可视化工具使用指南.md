# 多重射击控制器可视化工具使用指南

## 概述

本项目提供了多种可视化工具来分析和展示多重射击DPCBF控制器的仿真结果。经过修复和优化，推荐使用 **`multishooting_visualizer.py`** 作为主要的可视化工具。

## 可视化工具对比

| 工具名称 | 功能特点 | 推荐使用场景 | 状态 |
|---------|---------|-------------|------|
| `multishooting_visualizer.py` | ⭐ 最全面，兼容性好 | 日常分析，报告生成 | ✅ 推荐 |
| `enhanced_visualizer.py` | 功能丰富，有兼容性问题 | 高级分析，需要调试 | ⚠️ 需修复 |
| `unified_visualizer.py` | 基础功能 | 简单场景分析 | ⚠️ 功能有限 |
| `ms_visualizer.py` | 原始版本 | 兼容性测试 | ❌ 有bug |

## 🚀 推荐使用：multishooting_visualizer.py

### 主要功能

1. **6面板综合分析图**：
   - 车辆轨迹图（主车+障碍物+参考轨迹）
   - 速度曲线分析
   - 安全距离监控（CBF约束）
   - 控制输入分析（转向角+加速度）
   - 车辆方向角变化
   - 障碍物距离监控

2. **实时动画**：
   - 动态轨迹显示
   - 安全区域可视化
   - 实时状态信息
   - 多车辆轨迹跟踪

3. **详细统计报告**：
   - 轨迹分析（距离、速度统计）
   - 控制输入分析（最大值、标准差）
   - 安全性分析（危险时刻检测）
   - 方向角分析（转向角度变化）

### 使用方法

#### 1. 基本使用

```bash
# 自动检测并可视化CSV文件
python3 viz/multishooting_visualizer.py

# 指定特定场景类型
python3 viz/multishooting_visualizer.py --scenario straight
python3 viz/multishooting_visualizer.py --scenario intersection

# 指定具体CSV文件
python3 viz/multishooting_visualizer.py --csv test_ms_intersection_output.csv
```

#### 2. 选项参数

```bash
# 只生成静态分析图
python3 viz/multishooting_visualizer.py --static-only

# 只生成动画
python3 viz/multishooting_visualizer.py --animation-only

# 列出可用的CSV文件
python3 viz/multishooting_visualizer.py --list

# 查看帮助信息
python3 viz/multishooting_visualizer.py --help
```

#### 3. 完整工作流程

```bash
# 步骤1：运行仿真生成数据
./test_multiple_shooting --controller=multiple --scenario=intersection --save_csv=true

# 步骤2：生成静态分析
python3 viz/multishooting_visualizer.py --csv test_ms_intersection_output.csv --static-only

# 步骤3：生成动画（可选）
python3 viz/multishooting_visualizer.py --csv test_ms_intersection_output.csv --animation-only

# 步骤4：完整分析
python3 viz/multishooting_visualizer.py --csv test_ms_intersection_output.csv
```

### 输出文件

脚本会自动生成以下文件：

- `{filename}_analysis.png` - 6面板静态分析图
- `{filename}_animation.gif` - 实时动画（如果选择生成）

### 数据格式要求

CSV文件应包含以下列：

**必需列**：
- `t` - 时间 (秒)
- `x`, `y` - 车辆位置 (米)
- `v` - 速度 (米/秒)
- `steer` - 转向角 (弧度)
- `a` - 加速度 (米/秒²)

**可选列**：
- `theta` - 方向角 (弧度)
- `h_min` - 最小安全距离
- `ref_x`, `ref_y` - 参考轨迹位置
- `obs{i}_ox`, `obs{i}_oy` - 障碍物i的位置
- `obs{i}_r` - 障碍物i的半径
- `obs{i}_vx`, `obs{i}_vy` - 障碍物i的速度

### 关键指标解读

1. **轨迹分析**：
   - `Total distance`：车辆实际行驶距离
   - `Average velocity`：平均速度
   - `Max/Min velocity`：速度范围

2. **控制输入分析**：
   - `Max steering`：最大转向角（越小越平滑）
   - `Steering std`：转向角标准差（越小越稳定）
   - `Max acceleration`：最大加速度

3. **安全性分析**：
   - `Min safety distance`：最小安全距离（>0表示安全）
   - `Unsafe moments`：不安全时刻数量
   - `Unsafe time range`：不安全时间段

## 🔧 故障排除

### 1. 找不到CSV文件

```bash
# 检查当前目录下的CSV文件
ls -la *output*.csv

# 列出可用的CSV文件
python3 viz/multishooting_visualizer.py --list

# 使用完整路径
python3 viz/multishooting_visualizer.py --csv /path/to/your/file.csv
```

### 2. 动画生成失败

```bash
# 检查pillow库是否安装
pip show pillow

# 安装pillow
pip install pillow

# 如果仍有问题，只生成静态分析
python3 viz/multishooting_visualizer.py --static-only
```

### 3. 数据格式错误

确保CSV文件包含必需的列：
```bash
# 查看CSV文件的列名
head -1 your_file.csv

# 应该包含：t,x,y,v,steer,a
```

### 4. 内存不足

对于大型数据集：
```bash
# 只生成静态分析
python3 viz/multishooting_visualizer.py --static-only

# 或者减少数据点
```

## 📈 性能优化建议

1. **大数据集处理**：
   - 使用 `--static-only` 参数
   - 考虑数据采样

2. **动画优化**：
   - 调整 `interval` 参数降低帧率
   - 减少轨迹尾迹长度

3. **批量处理**：
   ```bash
   # 批量处理多个文件
   for file in *output*.csv; do
       python3 viz/multishooting_visualizer.py --csv "$file" --static-only
   done
   ```

## 🚨 注意事项

1. **数据完整性**：确保CSV文件包含所有必需的列
2. **内存管理**：大型数据集可能需要较多内存
3. **动画文件大小**：生成的GIF文件可能较大
4. **依赖库版本**：确保使用兼容版本的pandas、numpy、matplotlib

## 📞 技术支持

如果遇到问题：

1. 检查数据格式是否正确
2. 确认所有依赖库已安装
3. 尝试使用 `--static-only` 参数
4. 查看错误信息的详细信息
