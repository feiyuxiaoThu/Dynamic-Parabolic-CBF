# 多重打靶控制器技术文档

## 概述

本文档详细说明了DPCBF-QP项目中多重打靶控制器（MultipleShootingController）的实现原理。该控制器的核心特点是：**优化变量只包含控制输入（加速度a和转向角steer），而不包含车辆状态变量**。状态变量通过车辆动力学模型在每次迭代中重新计算。

## 核心设计思想

### 1. 控制变量优化的优势

传统的多重打靶方法通常将状态变量和控制变量都作为优化变量，这会导致：
- 优化变量维度高（每个时间步都有4个状态变量 + 2个控制变量）
- 需要额外的等式约束来保证动力学一致性
- 计算复杂度高

本实现采用控制变量优化策略：
- **优化变量：** 只有控制输入 `[steer, a]`
- **状态变量：** 通过动力学模型从控制输入积分得到
- **优势：** 变量维度减半，计算效率更高

## 系统架构

### 1. 基本数据结构

#### ShootingNode（射击节点）
```cpp
struct ShootingNode {
    State state;          // [x, y, θ, v] 车辆状态
    Control control;      // [steer, a] 控制输入
    double time;          // 时间戳
    bool is_fixed;        // 是否固定（不参与优化）
};
```

#### 核心参数
```cpp
struct MultipleShootingParams {

    double dt{0.05};              // 时间步长
    double weight_control{12.0};   // 控制偏差权重
    double weight_rate{5.0};       // 控制变化率权重
    // ... 其他参数
};
```

### 2. 优化问题构建

#### 变量设置
- **优化变量数量：** `horizon × 2` （每个时间步的steer和a）
- **变量排列：** `[steer₀, a₀, steer₁, a₁, ..., steer_{N-1}, a_{N-1}]`

#### 目标函数
```
min  Σ_{k=0}^{N-1} [w_c||u_k - u_ref||² + w_r||u_k - u_{k-1}||²]
```
其中：
- `w_c`：控制偏差权重
- `w_r`：控制变化率权重
- `u_ref`：参考控制输入

## 关键实现机制

### 1. 状态变量联系机制（核心问题）

**关键问题**：在只优化控制变量 `[steer, a]` 的情况下，如何保证车辆状态变量 `[x, y, θ, v]` 之间的物理联系？

**答案**：通过**三重约束机制**保证状态变量的物理一致性：

#### 1.1 主要机制：动力学线性化约束

对每个相邻时间步 `[k, k+1]` 添加4个线性化约束：

```
B * δu = residual
```

具体形式：
- **x位置约束**：`∂x/∂steer * δsteer + ∂x/∂a * δa = residual_x`
- **y位置约束**：`∂y/∂steer * δsteer + ∂y/∂a * δa = residual_y`
- **θ角度约束**：`∂θ/∂steer * δsteer + ∂θ/∂a * δa = residual_θ`
- **v速度约束**：`∂v/∂steer * δsteer + ∂v/∂a * δa = residual_v`

其中：
- `B` 是控制雅可比矩阵 `∂f/∂u` (4×2)
- `residual` 是预测状态与期望状态的偏差
- 这4个约束确保优化后的控制能够产生符合物理动力学的状态变化

#### 1.2 辅助机制：初始化一致性保证

- **初始状态固定**：第一个节点的状态是真实的车辆状态，不可更改
- **动力学一致性**：每个后续节点都通过 `model_.step()` 从前一个节点计算得到
- **控制-状态匹配**：每个节点的控制输入都能产生对应的状态变化

#### 1.3 最终保证：重新积分重构

从优化后的控制序列重新积分得到状态轨迹：
```cpp
State current_state = nodes[0].state;  // 固定的初始状态
for (const auto& control : result.control_sequence) {
    current_state = model_.step(current_state, control);  // 严格动力学积分
    result.state_trajectory.push_back(current_state);
}
```

### 2. 状态变量计算流程

#### 初始化阶段（`initializeShootingNodes`）
```cpp
// 1. 第一个节点：固定初始状态
ShootingNode first_node;
first_node.state = initial_state;    // 固定，不优化
first_node.control = u_ref;          // 参考控制
first_node.is_fixed = true;

// 2. 后续节点：基于参考轨迹预测
for (int i = 1; i <= horizon; ++i) {
    ShootingNode node;
    if (有参考轨迹) {
        node.state = reference_trajectory[i];
        node.control = computeControlForReference(current_state, node.state);
    } else {
        node.state = model_.step(current_state, current_control);
        node.control = u_ref;
    }
    node.is_fixed = false;  // 后续节点可优化
}
```

#### 优化过程中的状态更新
在QP求解过程中，状态变量**不直接参与优化**，而是通过以下方式处理：

1. **动力学约束：** 在 `addDynamicsConstraints` 中，每个时间步的动力学约束确保：
   ```
   x_{k+1} = f(x_k, u_k)  // 通过线性化的动力学模型
   ```

2. **线性化处理：**
   ```cpp
   void linearizeDynamics(const ShootingNode& node,
                          const State& next_state,
                          Eigen::Matrix4d& A_mat,
                          Eigen::Matrix<double, 4, 2>& B_mat);
   ```
   - `A_mat = ∂f/∂x`：状态雅可比矩阵
   - `B_mat = ∂f/∂u`：控制雅可比矩阵

### 2. 动力学约束实现

#### 约束形式
每个射击节点间添加4个状态约束：
```
A * δu = residual
```
其中：
- `A`：控制雅可比矩阵 `B_mat`
- `δu`：控制变量变化量
- `residual`：预测状态与目标状态的偏差

#### 具体实现（`addDynamicsConstraints`）
```cpp
for (int i = 0; i < nodes.size() - 1; ++i) {
    const auto& current_node = nodes[i];
    const auto& next_node = nodes[i + 1];

    // 1. 线性化动力学
    Eigen::Matrix4d A_mat;
    Eigen::Matrix<double, 4, 2> B_mat;
    linearizeDynamics(current_node, next_node.state, A_mat, B_mat);

    // 2. 计算残差
    State predicted = model_.step(current_node.state, current_node.control);
    Eigen::Vector4d residual;
    residual << next_node.state.x - predicted.x,
                next_node.state.y - predicted.y,
                next_node.state.theta - predicted.theta,
                next_node.state.v - predicted.v;

    // 3. 为每个状态变量添加约束
    for (int state_idx = 0; state_idx < 4; ++state_idx) {
        int control_idx = i * 2;
        // 约束：B_mat(state_idx,:) * [steer, a]^T = residual(state_idx)
        a_triplets.emplace_back(constraint_row, control_idx, B_mat(state_idx, 0));
        a_triplets.emplace_back(constraint_row, control_idx + 1, B_mat(state_idx, 1));

        l_(constraint_row) = residual(state_idx);
        u_(constraint_row) = residual(state_idx);  // 等式约束
        constraint_row++;
    }
}
```

### 3. 安全约束处理

#### CBF约束实现
动态抛物线控制屏障函数（DPCBF）约束同样基于状态变量，但通过链式法则转换为对控制变量的约束：

```cpp
void computeCBFGradients(const ShootingNode& node,
                         const Obstacle& obstacle,
                         Eigen::Vector4d& cbf_grad,
                         Eigen::Vector2d& cbf_control_grad) {

    // 1. 计算CBF对状态的梯度 ∇h/∂x
    cbf_grad = 数值微分计算;

    // 2. 通过链式法则计算对控制的梯度
    // ∇h/∂u = ∇h/∂x * ∂x/∂u = ∇h/∂x * B
    Eigen::Matrix4d A_mat;
    Eigen::Matrix<double, 4, 2> B_mat;
    linearizeDynamics(node, model_.step(node.state, node.control), A_mat, B_mat);

    cbf_control_grad = B_mat.transpose() * cbf_grad;
}
```

#### 约束形式
```
∇h/∂u * δu ≥ -constraint_value
```
其中 `constraint_value` 是离散CBF约束项：
```
h_{k+1} - h_k + γ * h_k ≥ 0
```

### 4. 结果提取与验证

#### 从控制解重构状态轨迹（`extractResults`）
```cpp
MultipleShootingResult extractResults(const Eigen::VectorXd& solution,
                                     const std::vector<ShootingNode>& nodes) {
    // 1. 提取控制序列
    for (int i = 0; i < horizon; ++i) {
        Control control;
        control.steer = solution(i * 2);      // 优化得到的转向角
        control.a = solution(i * 2 + 1);      // 优化得到的加速度
        result.control_sequence.push_back(control);
    }

    // 2. 重新积分得到状态轨迹
    State current_state = nodes[0].state;
    result.state_trajectory.push_back(current_state);

    for (const auto& control : result.control_sequence) {
        current_state = model_.step(current_state, control);  // 动力学积分
        result.state_trajectory.push_back(current_state);
    }
}
```

## 算法优势分析

### 1. 计算效率
- **变量维度减少50%**：从 `6×horizon` 减少到 `2×horizon`
- **约束数量合理**：主要是动力学约束和安全约束，避免冗余的状态等式约束
- **QP求解更快**：稀疏结构更明确，数值条件更好

### 2. 数值稳定性
- **避免状态变量累积误差**：每次迭代都重新积分状态
- **更好的物理一致性**：通过动力学模型严格保证状态连续性
- **约束条件更紧致**：避免状态变量优化中可能出现的不一致解

### 3. 实现复杂度
- **代码结构清晰**：控制优化和状态计算分离
- **调试方便**：可以直接检查控制序列的合理性
- **扩展性好**：易于添加新的约束类型

## 与传统方法的对比

| 特性 | 传统多重打靶 | 本实现方法 |
|------|-------------|------------|
| 优化变量 | 状态 + 控制 | 仅控制 |
| 变量维度 | 6×horizon | 2×horizon |
| 约束类型 | 动力学等式 + 不等式 | 线性化动力学 + 不等式 |
| 计算复杂度 | 高 | 中等 |
| 数值稳定性 | 依赖初始猜测 | 依赖动力学模型精度 |
| 实现难度 | 高 | 中等 |

根据环境复杂度动态调整预测时域：
```cpp
int adaptHorizon(const State& state, const std::vector<Obstacle>& obstacles) {

    double safety_factor = std::exp(-min_distance / 5.0);
    double speed_factor = max_relative_speed / 10.0;

    int adapted_horizon = static_cast<int>(horizon * (1.0 + 2.0 * safety_factor + speed_factor));
    return std::max(5, std::min(20, adapted_horizon));
}
```

## 总结

本实现的多重打靶控制器通过**只优化控制变量**的策略，在保证性能的同时显著提高了计算效率。关键创新点包括：

1. **控制变量优化**：减少优化维度，提高求解速度
2. **动力学一致性保证**：通过线性化约束确保状态连续性
3. **自适应时域**：根据环境复杂度动态调整预测长度
4. **鲁棒性设计**：多层次的回退策略保证系统可靠性

这种方法特别适合实时应用场景，如自动驾驶中的轨迹规划与控制，在保证安全性的同时满足实时性要求。
