# DPCBF 超参数自适应调节策略说明

本文档基于论文 [Dynamic Parabolic Control Barrier Functions for Safe Control of Nonlinear Systems](https://arxiv.org/html/2510.01402v1) 和当前代码库，深入探讨 DPCBF (Dynamic Parabolic Control Barrier Function) 中关键超参数 `k_lambda` 和 `k_mu` 的自适应调节策略。

## 1. DPCBF 的内在自适应性

首先必须明确，DPCBF 的核心优势在于其**内在的自适应能力**。与传统的使用固定形状安全集的 CBF 不同，DPCBF 的安全集（一个抛物面）的形状是动态变化的。

在代码 `dpcbf.cc` 中，控制屏障 `h` 的核心参数 `λ` 和 `μ` 是通过以下方式计算的：

```cpp
// dpcbf.cc
double scale = std::sqrt(p.margin*p.margin - 1.0) / (ego_dim + p.eps);
double lam = (p.k_lambda * scale) * std::sqrt(dsafe) / (vr + p.eps);
double mu  = (p.k_mu     * scale) * std::sqrt(dsafe);

res.h = vxl + lam * (vyl*vyl) + mu;
```

- `lam` (即论文中的 `λ`)：与 `sqrt(dsafe)` (距离的函数) 成正比，与 `vr` (相对速度大小) 成反比。
- `mu` (即论文中的 `μ`)：与 `sqrt(dsafe)` (距离的函数) 成正比。

这意味着：
- **距离越远 (`dsafe` 越大)**，`λ` 和 `μ` 越大，安全集范围越大，允许控制器有更宽松的规划空间。
- **相对速度越快 (`vr` 越大)**，`λ` 越小，抛物线越“开放”，允许更大的侧向速度，以适应高速交汇时的避让场景。

因此，DPCBF 本身就已经通过 `λ` 和 `μ` 的动态计算实现了对环境的自适应。

## 2. 超参数 `k_lambda` 和 `k_mu` 的物理意义

`k_lambda` 和 `k_mu` 并不是 CBF 的直接参数，而是用于调节 `λ` 和 `μ` 计算公式的**超参数**。它们像是调节自适应灵敏度的“旋钮”。

- **`k_mu` (前向缓冲调节器)**：
  - **物理意义**: `k_mu` 主要决定了**前向安全缓冲**的基准大小。它控制了机器人对正前方碰撞风险的敏感度。
  - **调节效果**:
    - **增大 `k_mu`**: 会不成比例地增加 `μ` 的值，使得安全集在前方（Line-of-Sight 方向）延伸得更远。这会导致机器人**更早地减速**，即使障碍物只是在很远的正前方。策略更保守。
    - **减小 `k_mu`**: 会让机器人对前方障碍物的反应不那么敏感，允许其在更近的距离上才开始减速。策略更激进。

- **`k_lambda` (侧向惩罚调节器)**：
  - **物理意义**: `k_lambda` 主要决定了抛物线安全集的“开口宽度”，即对**侧向相对速度** (`vyl`) 的惩罚权重。
  - **调节效果**:
    - **增大 `k_lambda`**: 会增加 `λ` 的值，使得 `h` 对 `vyl` 的平方项更加敏感。这意味着即使是很小的侧向速度也会导致 `h` 快速减小，从而触发制动。这会迫使机器人倾向于**“减速-等待”**策略，而不是“侧向绕行”。
    - **减小 `k_lambda`**: 会减小 `λ`，使得控制器对侧向速度有更大的容忍度，鼓励机器人采取**“侧向规避”**的策略。

## 3. 高级自适应策略：动态调节超参数

在理解了 `k_lambda` 和 `k_mu` 的作用后，我们可以设计更高级的策略，让这两个超参数本身也根据更高维度的状态信息进行自适应调节。

这相当于给控制器增加了一个“情景感知”层。

### 策略一：基于自身速度的调节

当机器人自身速度 `v` 较高时，系统惯性大，反应时间短，需要更保守的策略。

- **建议实现**:
  - `k_mu_adaptive = k_mu_base * (1 + c_v * s.v)`
  - `k_lambda_adaptive = k_lambda_base * (1 + c_v * s.v)`
  - 其中 `c_v` 是一个小的正常数，例如 `0.1`。
- **效果**: 速度越快，安全缓冲和侧向惩罚就越大，迫使机器人更早、更稳地进行避障。

### 策略二：基于碰撞时间 (TTC) 的调节

Time-to-Collision (TTC) 是一个衡量危险程度的优秀指标。当障碍物在视线方向上朝自己运动时，`TTC = 相对距离 / -相对径向速度`。

- **计算 TTC**:
  - `vxl` 是障碍物在 LoS 坐标系下的径向速度。如果 `vxl < 0`，则障碍物正在靠近。
  - `ttc = pr / (-vxl)`，其中 `pr` 是相对距离。
- **建议实现**:
  - 当 `vxl < -eps` 且 `ttc` 小于某个阈值（如 `5.0` 秒）时，认为风险增高。
  - `k_mu_adaptive = k_mu_base + c_ttc / (ttc + eps)`
  - `k_lambda_adaptive = k_lambda_base + c_ttc / (ttc + eps)`
  - 其中 `c_ttc` 是一个正常数，例如 `0.5`。
- **效果**: 随着碰撞时间缩短，风险急剧升高，`k_mu` 和 `k_lambda` 会非线性地急剧增大，产生强烈的“紧急制动”和“保持姿态”效果，优先确保安全。

### 策略三：基于参考路径曲率的调节

当机器人在高曲率的参考路径上行驶时，其转向能力已经大部分被用于循迹，因此额外的避障机动能力受限。

- **计算曲率**: 在 `sim.cpp` 中，我们已经计算了参考轨迹的曲率 `kappa`。
- **建议实现**:
  - `k_mu_adaptive = k_mu_base * (1 + c_k * abs(kappa))`
  - `k_lambda_adaptive = k_lambda_base * (1 + c_k * abs(kappa))`
  - 其中 `c_k` 是一个正常数，例如 `0.2`。
- **效果**: 在弯道上，机器人会变得更加保守，倾向于提前减速避障，而不是试图在弯道上进行剧烈的绕行动作。

### 4. 如何在代码中实现

要实现这些策略，你需要修改 `dpcbf_continuous` 函数（或调用它的地方），在计算 `lam` 和 `mu` 之前，根据当前的机器人状态 `s`、障碍物状态 `obs` 和参考路径信息 `kappa` 等，先计算出临时的 `k_lambda_adaptive` 和 `k_mu_adaptive`，然后用它们来代替固定的 `p.k_lambda` 和 `p.k_mu`。

`margin` 和 `eps` 通常作为固定参数，`margin` 定义了不可侵犯的最小安全边界，而 `eps` 是为了数值稳定性，一般无需调节。
